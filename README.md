CFD project analyzing airfoils in ground effect across various angles of attack.

Results and poster are found at CFD poster.pdf

NACAPoints.dat and S1223Points.dat are different data files for the geometry of airfoils we tested.

finalscript.py is the full code for solving the actual fluids problem and analyzing the airfoils.

job.sh was used for uploading our script to the CU Research Supercomputer Cluster (run simulations way faster).

meshgen.py was for a python script that automatically generates meshes for the user using only data file as input.

turbulentmodel.py was the base model for our final script, as we were assuming turbulent flow.
